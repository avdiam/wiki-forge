## Consensus: Multi-LLM Support via WORKFLOWS.md

### What to build

**1. `WORKFLOWS.md` template** (new file in `skills/wiki-init/templates/`)

A universal, LLM-agnostic instruction file installed into `wiki/` by `wiki-init`. Describes every operation as step-by-step instructions using generic terminal commands + LLM judgment. Sections:

- **Ingest a source** — pre-process with `ingest_source.py`, read source, grep for existing pages, create/edit pages per AGENTS.md rules, run `update_index.py`, run `append_log.py`, git commit
- **Query the wiki** — run threshold check, search or read indices, synthesize with citations, optionally file as synthesis page
- **Lint the wiki** — run `lint_wiki.py --json`, run `graph_analyzer.py --json`, read flagged pages for semantic review, produce report
- **Capture from URL** — fetch content, normalize to markdown, write to vault with frontmatter, then follow ingest workflow
- **View the log** — grep `log.md` for entries

Uses generic language ("use your terminal", "use your filesystem search") instead of Claude-specific tool names.

Includes a **Context management** section with explicit guidance: "After reading a large source, synthesize your notes and prune the raw text from your working memory before editing pages."

**2. Update AGENTS.md template** (edit existing `skills/wiki-init/templates/CLAUDE.md`)

Add a pointer section:

> "If your platform does not support Claude Code's `/skills` commands or subagent dispatch, refer to `WORKFLOWS.md` for step-by-step manual execution instructions. All operations can be performed using terminal commands and the helper scripts in `.scripts/`."

**3. Thin IDE pointer files** (generated by `wiki-init`)

During init, optionally generate in the project root:
- `.cursorrules` — points to `wiki/AGENTS.md` and `wiki/WORKFLOWS.md`
- `.windsurfrules` — same pointer

These are 2-3 line files. Low effort, high discoverability.

**4. Update `wiki-init` SKILL.md**

Add a step to install `WORKFLOWS.md` and optionally generate the IDE pointer files.

### What stays unchanged

- Claude Code skills and agents — no degradation of the first-class experience
- Existing CLAUDE.md/AGENTS.md content — only a pointer added
- Python scripts — already portable, no changes needed
